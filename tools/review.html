Candidate review

For each candidate: watch the clip (the source time is burned in, top left), then Y if it is a real event with roughly right bounds, N if it is not, or edit start / end / class and press F. tIoU 0.7 is strict: set bounds to where the behaviour starts and stops. [ / ] copy the playing video's time into start / end. "recall probe" candidates are near misses the pipeline did NOT report; confirming one marks a miss. "scan" cards are only places to look for stopped vehicles, wrong-way driving and congestion: most will be N. Add anything else you saw with "Add a missed event". Unreviewed candidates are left out of the export.
